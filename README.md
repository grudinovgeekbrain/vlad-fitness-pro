# Vlad Fitness Pro — сайт и система заявок

## Что входит
- `index.html` — адаптивный лендинг с формой заявки.
- `assets/` — рекламные визуалы для сайта.
- `netlify/functions/lead.mjs` — серверная функция, которая отправляет заявку в Telegram.
- `netlify.toml` — конфигурация публикации на Netlify.
- `lead-tracker-template.csv` — шаблон учёта заявок, который можно открыть в Excel или импортировать в Google Sheets.
- `instagram-telegram-plan.md` — позиционирование, оформление профиля и контент-план на 30 дней.

## Как работает запись
1. Посетитель заполняет форму на сайте.
2. Сайт отправляет данные в серверную функцию Netlify.
3. Функция присылает тебе уведомление в Telegram.
4. Ты связываешься с человеком и подтверждаешь дату/время отдельно.

Отправленная форма — это **заявка**, а не подтверждённая запись. Для учёта используй статусы: `Новая`, `Связался`, `Записан`, `Пришёл`, `Не ответил`, `Отказ`.

## Обязательная настройка Telegram
1. В Telegram открой `@BotFather`, отправь `/newbot` и создай бота. Сохрани токен приватно.
2. Открой чат с новым ботом и нажми **Start**, затем отправь любое сообщение.
3. Узнай chat ID. В браузере открой `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates`, заменив `ВАШ_ТОКЕН` токеном. Найди `message` → `chat` → `id`. Если обновления пустые, отправь боту ещё сообщение и повтори запрос.
4. **Не отправляй токен в переписке, не добавляй его в HTML и не помещай в публичный репозиторий.**
5. Опубликуй проект на Netlify с поддержкой функций (см. следующий раздел).
6. В настройках сайта Netlify добавь environment variables:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - `TELEGRAM_CHAT_ID` = твой chat ID
7. Выполни повторную публикацию (redeploy), чтобы функция получила настройки.
8. Открой опубликованный сайт и отправь тестовую заявку. Убедись, что сообщение пришло в Telegram. Не запускай рекламу, пока тест не прошёл.

## Публикация на Netlify
Поскольку проект использует `netlify/functions/lead.mjs`, **одной загрузки статической папки через Netlify Drop недостаточно для надёжной работы формы**. Нужно задеплоить сайт с функцией, например:
- через Netlify CLI: установить Node.js, затем выполнить `npm install -g netlify-cli`, перейти в папку проекта и выполнить `netlify deploy`. Для публикации в продакшен — `netlify deploy --prod`.
- либо разместить проект в Git-репозитории и подключить репозиторий в Netlify, указав корневую папку проекта. Конфигурация `netlify.toml` уже указывает publish directory `.` и functions directory `netlify/functions`.

Не вставляй токен в код и не публикуй файл с секретами.
